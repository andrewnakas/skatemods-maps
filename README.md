# skatemods maps

Storage for community Skate 3 maps published on [skatemods.com](https://skatemods.com/maps/). Each release is one approved map: the original upload plus its conversions (recomp `.big`, `.skate`).

Every map was uploaded by its author or with the author's permission and reviewed by a moderator. Browse and download from [skatemods.com/maps](https://skatemods.com/maps/); report problems with the Report button on the map page or see the [takedown policy](https://skatemods.com/policy/#takedowns).

Maps are licensed by their authors as shown on each release. Skate 3 is a trademark of Electronic Arts; this project is not affiliated with EA.
